# Acos API Documentation
This is the source for https://acosas.github.io/

Committing changes to this repo will affect the site.

## Theme for Jekyll
This site is based on a theme from [Tom Johnson](https://github.com/tomjoht)<br/>
Site: [Documentation Theme for Jekyll](https://idratherbewriting.com/documentation-theme-jekyll/)

# Making changes

Manual API text lives in `overlays/<product>/` (fragments and `placements.yml`)
and in standalone guides under `pages/userapi/` and `pages/mottakwebapi/`.
Do not edit generated REST stubs in `pages/swagger/` or compose output
(`_data/overlays.yml`, `_includes/overlays/`, `*_index.md` written by compose,
structured `*_sidebar.yml`).

## Install Ruby and Jekyll

Use **Ruby 3.2** (see `.ruby-version`). Do not install Bundler 4 or a global
Jekyll 4 into `GEM_HOME`; they collide with this site's Jekyll 3.9 bundle.

Windows: enable WSL, then in Ubuntu:

```sh
sudo apt-get install ruby-full build-essential zlib1g-dev
echo 'export GEM_HOME="$HOME/gems"' >> ~/.bashrc
echo 'export PATH="$HOME/gems/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
gem install bundler -v '~> 2.4.22'
```

Install the OpenAPI helper (until 1.6.0 is on RubyGems):

```sh
gem install --local path/to/acos_jekyll_openapi_helper-1.6.0.gem
cd /mnt/d/Kode/github/Acos.Integration.Documentation
bundle install
```

The Gemfile pins Jekyll **3.9.5**, `kramdown-parser-gfm` (for `kramdown.input: GFM`)
and `rexml` (removed from Ruby 3.2 default gems). Jekyll 4 is a later upgrade
because this Tom Johnson theme still targets 3.x.

## Update gems
```sh
bundle update
```

## Rebuild OpenAPI pages

`build_pages.sh` writes REST stubs only. Overlay compose must run afterwards
(sidebars, overview pages and customer notes):

```sh
./scripts/rebuild-docs.sh
```

Optional: regenerate one API, then compose all overlays:

```sh
./scripts/rebuild-docs.sh arkivmelding.json
```

`rebuild-docs.sh` runs `build_pages.sh` then `scripts/compose-overlays.py`.

## Serve site

`bundle exec jekyll` often misses the Jekyll binstub on Ruby 3. Use the wrapper,
which loads Jekyll from the **bundle** (not `~/gems/bin/jekyll`):

```sh
./scripts/rebuild-docs.sh
./scripts/jekyll-serve.sh
```

Open http://127.0.0.1:4000/

## Add documentation
To add a swagger OpenAPI JSON file, put it in `_data/swagger/` with a unique
name. Add `overlays/<product>/placements.yml` for guides, REST slots and
sidebar. Then run:

```sh
./scripts/rebuild-docs.sh
```

This produces REST stubs in `./pages/swagger`, overlay copies in
`_includes/overlays/`, `_data/overlays.yml`, composed index pages and
structured sidebar YAML.

In `_config.yml` add the sidebar file:

```yml
sidebars:
    - name: [name]_sidebar.yml
site_sidebars:
    - name: [name]_sidebar.yml
```

Test and validate changes.

To publish the site, push to git:

```ps
git push -u origin master
```

If remote is not added:

```ps
git remote add origin https://github.com/ACOSAS/acosas.github.io.git
```

REST stubs are generated by a gem.<br/>
Source: [github](https://github.com/ACOSAS/acos_jekyll_openapi_helper.git)
Version 1.6.0 writes stubs only. Sidebars come from overlay compose.
